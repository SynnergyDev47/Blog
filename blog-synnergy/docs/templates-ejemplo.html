Ejemplos de templates HTML — Solo documentación

Este archivo no es una página del sitio. Es un ejemplo educativo que muestra cómo se usarían motores de templates para generar las páginas de Synnergy Blog dinámicamente.

Ejemplo con Jinja2 (Python)

Jinja2 se usa en frameworks como Flask y Django. Las plantillas usan {% %} para lógica y {{ }} para variables.

Primero se define una plantilla base con bloques reemplazables:

<!-- archivo: templates/base.html -->
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">

  <!-- CONCEPTO: Template Jinja2 — {{ variable }} inserta un valor dinámico -->
  <title>{{ titulo }} · Synnergy Blog</title>
  <meta name="description" content="{{ descripcion }}">
</head>
<body>
  <header role="banner">
    <h1>Synnergy Blog</h1>
    <nav role="navigation" aria-label="Navegación principal">
      <ul>
        <li><a href="/">Inicio</a></li>
        <li><a href="/about">Sobre mí</a></li>
        <li><a href="/contacto">Contacto</a></li>
      </ul>
    </nav>
  </header>

  <main role="main">
    <!-- CONCEPTO: Template Jinja2 — {% block %} define una zona reemplazable -->
    {% block contenido %}{% endblock %}
  </main>

  <footer role="contentinfo">
    <hr>
    <p>&copy; 2026 Aurelio Crespo &amp; Synnergy Lab</p>
  </footer>
</body>
</html>

Luego, la página de inicio hereda de la base y rellena el bloque:

<!-- archivo: templates/index.html -->

<!-- CONCEPTO: Template Jinja2 — {% extends %} hereda de plantilla base -->
{% extends "base.html" %}

<!-- CONCEPTO: Template Jinja2 — {% block %} reemplaza el contenido del bloque padre -->
{% block contenido %}
  <section aria-labelledby="articulos-recientes">
    <h2 id="articulos-recientes">Artículos recientes</h2>
    <ul>
      <!-- CONCEPTO: Template Jinja2 — {% for %} itera sobre una colección -->
      {% for articulo in articulos %}
        <li>
          <a href="{{ articulo.url }}">{{ articulo.titulo }}</a>
          <small>— {{ articulo.fecha }} · {{ articulo.categoria }}</small>
        </li>
      {% endfor %}
    </ul>
  </section>
{% endblock %}

Los datos vendrían del backend (por ejemplo, Flask):

# archivo: app.py (Python / Flask)
from flask import Flask, render_template

app = Flask(__name__)

@app.route("/")
def inicio():
    articulos = [
        {
            "titulo": "Bienvenido a Synnergy Blog",
            "url": "/articles/mi-primer-articulo",
            "fecha": "2026-07-10",
            "categoria": "General"
        },
        {
            "titulo": "ARM vs x86: el chip que cambió mi forma de trabajar",
            "url": "/articles/arm-arquitectura",
            "fecha": "2026-07-11",
            "categoria": "Hardware"
        }
    ]
    return render_template("index.html",
                           titulo="Inicio",
                           descripcion="Blog de Aurelio Crespo",
                           articulos=articulos)

Ejemplo con Liquid (Jekyll / Shopify)

Liquid se usa en Jekyll (sitios estáticos) y Shopify. Usa {% %} para lógica y {{ }} para variables, igual que Jinja2, pero con diferencias en herencia y componentes.

En Liquid no existe {% extends %}. En su lugar se usan {% include %} para insertar fragmentos reutilizables (parciales).

<!-- archivo: _includes/nav.html -->
<!-- CONCEPTO: Template Liquid — {% include %} inserta un parcial reutilizable -->
<nav role="navigation" aria-label="Navegación principal">
  <ul>
    <li><a href="/">Inicio</a></li>
    <li><a href="/about">Sobre mí</a></li>
    <li><a href="/contacto">Contacto</a></li>
  </ul>
</nav>

La página principal de Jekyll iteraría sobre los posts:

<!-- archivo: index.html (Jekyll) -->
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">

  <!-- CONCEPTO: Template Liquid — {{ variable }} inserta un valor dinámico -->
  <title>{{ site.title }}</title>
  <meta name="description" content="{{ site.description }}">
</head>
<body>
  <header role="banner">
    <h1>{{ site.title }}</h1>

    <!-- CONCEPTO: Template Liquid — {% include %} inserta el parcial de navegación -->
    {% include nav.html %}
  </header>

  <main role="main">
    <section aria-labelledby="articulos-recientes">
      <h2 id="articulos-recientes">Artículos recientes</h2>
      <ul>
        <!-- CONCEPTO: Template Liquid — {% for %} itera sobre una colección -->
        {% for post in site.posts %}
          <li>
            <a href="{{ post.url }}">{{ post.title }}</a>
            <small>— {{ post.date | date: "%Y-%m-%d" }} · {{ post.category }}</small>
          </li>
        {% endfor %}
      </ul>
    </section>
  </main>

  <footer role="contentinfo">
    <hr>
    <p>&copy; 2026 Aurelio Crespo &amp; Synnergy Lab</p>
  </footer>
</body>
</html>

Los datos en Jekyll vendrían de archivos Markdown con frontmatter YAML (por ejemplo, _posts/2026-07-11-arm-arquitectura.md).
