Categoría: Aplicación Web & Gestión Multimedia

Resumen del Proyecto

Plataforma para agencias de representación artística que permite a músicos y cantantes enviar maquetas de audio, currículum artístico y videos de demostración mediante un proceso por etapas guiado y accesible.

Funcionalidades Clave

  • Formulario de subida de maquetas con reproductor audio nativo `
  • Filtros por género musical, rango vocal y ubicación geográfica.
  • Panel de revisión simplificado para jurados y productores.

Tecnologías Utilizadas

  • Formularios & Multimedia: HTML5 Semantic Forms, `
  • Estilos & Layout: CSS Responsive Grid & Print stylesheet.
  • Manejo de Datos: API REST & Almacenamiento Seguro.
